## What this pipeline currently executes

The notebook implements the **drug-likeness filter cascade and ADMET-fallback profiling** stages of the four-phase framework, applied to ChEMBL bioactivity data for EGFR (CHEMBL203):

| Stage | Filter | Threshold | Behaviour |
|---|---|---|---|
| 1 | QED (drug-likeness) | ≥ 0.65 | Cheminformatics filter |
| 2 | Synthetic Accessibility (SAscore) | ≤ 5.0 | Synthesizability filter |
| 3 | Lipinski's Rule of Five | ≥ 3 of 4 satisfied | Drug-likeness checkpoint |
| 4 | Tanimoto novelty vs FDA EGFR drugs | ≤ 0.4 | Novelty filter |
| 5 | Physicochemical SGOL surrogate | MW 250–450; logP 1–4; TPSA 50–110 Å² | Stand-in for full SBVS |
| 6 | ADMET profiling | Rule-based fallback (ADMETlab API unreachable) | Conservative pharmacokinetic check |

**Result:** 181 input compounds → 11 ADMET-favourable leads spanning four distinct chemical scaffolds (mean Tanimoto similarity 0.31 to FDA-approved EGFR inhibitors).

## What this pipeline currently does NOT execute

This is critical context — please read this section before drawing conclusions from the results.

The current notebook performs **none** of the following:

1. **Real T2D molecular generation.** The input pool is drawn directly from ChEMBL EGFR actives, not generated by Chemformer or MolBART. The filter cascade is applied to existing data, not to de novo generative output.

2. **Structure-based simulation (SGOL).** AlphaFold2 protein-structure prediction and DiffDock pose generation were not run. A physicochemical descriptor window served as a surrogate for binding-affinity scoring.

3. **ADMETlab 2.0 multitask predictions.** The ADMETlab web service was unreachable from the execution environment at the time of computation; rule-based QSAR proxies (Veber, GSK 4/400, Pfizer 3/75) were used as a fallback.

4. **Retrosynthesis (DSF).** ASKCOS and IBM RXN were not executed against the surviving candidates. The pipeline terminates at the ADMET-favourable lead set.

5. **Trial-outcome feedback (CFI).** The closed-loop feedback phase requires longitudinal trial-outcome data that is not available; CFI is described in the manuscript but not demonstrated in the worked example.

These limitations are described in **Section 5.7 of the manuscript** ("Limitations of the Worked Example"). The current pipeline is a reproducible demonstration of the filter cascade and ADMET stages of the framework on real bioactivity data, sufficient to establish that the framework's load-bearing components can be implemented with public tooling. It is not a substitute for full T2D generation, structure-based SGOL, retrosynthesis-aware DSF, or trial-outcome CFI.

## How to run

### Option A: Google Colab (recommended)

1. Open the notebook in Colab: [EGFR_GenAI_Pipeline_Colab.ipynb](EGFR_GenAI_Pipeline_Colab.ipynb)
2. Click **Runtime → Run all**
3. Total runtime: approximately 3 minutes on a free Colab CPU instance

The notebook is self-contained: it installs all required libraries, queries the ChEMBL REST API, applies the filter cascade, and produces the output CSVs and figures.

### Option B: Local execution

```bash
git clone https://github.com/shuklaaks/EGFR-GenAI-Pipeline.git
cd EGFR-GenAI-Pipeline
pip install rdkit numpy pandas matplotlib requests
jupyter notebook EGFR_GenAI_Pipeline_Colab.ipynb
```

Tested with: Python 3.10, RDKit 2024.03, pandas 2.0+

## Reproducibility

This pipeline is designed to be fully reproducible from public data:

- **Input data:** Pulled directly from ChEMBL via the public REST API
- **Software:** All open-source (RDKit, requests, matplotlib)
- **Compute:** Standard cloud notebook environment
- **Random seeds:** Fixed in the notebook for deterministic output
- **External APIs at time of execution:** ChEMBL ✓ reachable; ADMETlab 2.0 ⚠ unreachable (fallback applied)

Anyone can re-run the notebook and obtain the same 181 → 11 funnel with the same final candidate set.
